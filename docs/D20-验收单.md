# D20 验收单：预览预算对齐原版 pruner

**日期**：2026-10-28
**分支**：`d20-align-pruner-budget` → 合并回 `local-main`
**触发**：用户发现压缩比 14.7%（10433→1467 字符），问「原版是多少」——查实原版保留量是我们的 3.4 倍。

---

## 一、事实（已读源码确认）

原版 `dsh-compaction-tool-result-pruner/lib/index.js:10-14`：

```js
const DEFAULTS = deepFreeze({
    thresholdChars: 8192,   // 超过才精简
    headChars: 4096,        // 头部保留
    tailChars: 1024         // 尾部保留
});
```

原版一条超长工具输出保留约 **5120+ 字符**（头 4096 + 标记 + 尾 1024），头尾比 **4:1**。

我们改动前：`DEFAULT_PREVIEW_LIMIT = 1500`，头尾比 1:2（尾 2 倍于头）。

| 维度 | 原版 | 改前（我们） | 改后（我们） |
|---|---|---|---|
| 触发阈值 | 8192 字符 | 8192 **字节**（更严，中文更早触发） | 不变 |
| 保留量 | ~5120 字符 | 1500 字符 | **5120 字符** |
| 头尾比 | 4:1 | 1:2 | **4:1** |
| 原文存档 | ❌ 剪掉即丢 | ✅ 100% 落盘 | ✅ 保留（超越原版处） |
| 压缩比（10k 输出） | ~50% | 14.7% | **~49%** |

**两处有意保留的差异**（不照抄的理由）：

1. **阈值按字节不按字符**：原版 8192 字符对中文低估 3 倍体积（D16 P3-1 修复），我们的字节口径更正确，不改。
2. **原文 100% 落盘存档**：原版剪掉即丢，我们有存档可回读。这是四层架构超越原版的部分，保留。
