# tiered-compaction 代码归类规范

> 状态：待拍板 · 版本 v0.2 · 更新 2026-11-02
> 变更说明：v0.2 按文档规范 v2.0 重排，补齐硬约束、验收编号、风险表；实读目录结构后修订任务清单。
> 变更说明：v0.1 初稿，确定分层目录方案。

## 1. 定位

把 tiered-compaction 仓库从「src 平铺 18 个文件、test 平铺 61 个文件」改成分层目录结构，给谁用：本仓库后续所有施工 AI；核心目标：文件按职责归位，新代码有明确的落位规则。

## 2. 硬约束（违反即重做）

- 不许改变任何运行时行为，原因：本次只移动文件、改 import 路径，全量测试必须保持 340 通过 1 跳过不变；
- 不许改 `package.json` 的 `files` 白名单以外新增发布目录时遗漏同步白名单，原因：npm 发布内容错误会导致插件装不上；
- 不许修改 `cordis.patch.yml` 中指向 `src/` 的 patch 路径语义，原因：宿主 bundle patch 依赖该文件定位模块，路径改错插件直接失效；
- 不许动工作区未提交的历史文档（docs 下 11 个未跟踪 .md），原因：共享仓库纪律，不覆盖他人未提交改动；
- 不许在移动文件时顺带重构函数逻辑，原因：最小改动，归类和重构混在一个 diff 里无法审计。

## 3. 范围外（这次不做）

- contract.js（1896 行）和 client.js（2279 行）的内部拆分重构：目录归类后另立规范再做，本次只移文件不拆逻辑；
- ESLint 目录级规则配置：代码规范 v1.1 的 lint 门禁接入另立任务；
- 历史文档（docs 未跟踪文件）的整理：不属于代码归类。

## 4. 结构/接口

### 4.1 目标目录结构（依据：实读 src/ client/ tools/ test/ 文件清单 + 文件职责名）

```text
src/
  index.js                      ← 入口，不动
  core/                         ← 压缩管线核心（无宿主依赖）
    lossless-fold.js
    spill-to-disk.js
    soft-pressure.js
    lossy-summarize.js
    summary-input.js
    engine.js
  guard/                        ← 安全与防护
    circuit-breaker.js
    single-writer-guard.js
    health-check.js
  session/                      ← 会话与状态关联
    checkpoint-source.js
    goal-switch.js
    lineage.js
    shared-stats.js
    tool-pairing.js
  host/                         ← 宿主接入层（patch、路由、观察者）
    contract.js
    tool-result-observer.js
    status-route.js
client/
  client.js                     ← 保持单文件，本次不拆
tools/
  generators/                   ← 预设生成器
    gen-ptc-tc.mjs
    gen-ptc-tc.ps1
    gen-standard-tc.mjs
    gen-standard-tc.ps1
  check-install.mjs             ← 安装校验，留根
  plugin-name.mjs               ← 留根（被 check-install 引用）
  out/                          ← 生成产物，不动
test/
  core/ guard/ session/ host/   ← 与 src/ 一一对应移动
  fixture/                      ← 不动
```

### 4.3 落位规则（给后续新代码）

| 新代码类型 | 落位 | 禁止 |
|---|---|---|
| 某一层压缩逻辑的修改/扩展 | 对应 src/core/ 文件内 | 不新建平铺文件 |
| 新增防护机制 | src/guard/ | 不放 src 根 |
| 宿主 API 对接 | src/host/ | 不混入 core/ |
| 客户端 UI | client/（超 500 行需先立拆分规范） | 不进 src/ |
| 预设生成脚本 | tools/generators/ | 不放 tools 根 |
