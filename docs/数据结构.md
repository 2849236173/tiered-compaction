# 数据结构

插件只维护两类持久状态：**会话事件**（宿主所有，插件读写）与**谱系表**（插件所有）。存档文件是旁挂的实体。

## 会话事件

插件不自定义事件类型，只使用宿主的既有类型，并追加记账事件。

### 读取的事件

| 类型 | 用途 | 内容位置 |
|---|---|---|
| `user/message` | 选区内容、压缩边界 | `data.content` |
| `assistant/message` | 选区内容 | `data.message.content` |
| `tool/result` | 第 1-2 层处理对象 | `data.message.content` |
| `system/message` | 会话 system 头（不进选区） | `data.message.content` |
| `request/context` | 读上下文窗口大小 | `data.contextWindow` |
| `turn/start` `turn/end` | 取当前 open turn | `data.turn` |

> 内容位置不统一是宿主真实形态：只有 `user/message` 挂 `data.content`，其余消息挂 `data.message.content`。两者都得试，否则助手回复与工具结果会一个字都读不到。

### 写入的事件

| 类型 | 时机 | 必填字段 |
|---|---|---|
| `compaction/start` | 摘要事务开始 | `compactionId`、`turn` |
| `compaction/summary` | 摘要完成 | `compactionId`、`summary`、`shadowedRange`、`shadowedSeqs`、`shadowedTokenCount`、`provider`、`model` |
| `compaction/end` | 事务结束（成功或失败） | `compactionId`、`turn`，失败时加 `error` |
| `user/message` | 检查点写入 | content 三段 + `surfaceOp: {op:"replace"}` |

`turn` 必填：宿主格式契约对这两个事件要求该字段，缺失时当下不报错，但格式校验、迁移或恢复时会被拒绝。

## 表面（surface）

会话表面是**位置有序**的节点序列，`session.surface.nodes` 是 **seq 数字数组**。

**seq 不单调**：一次 `replace` 会把新事件的 seq 放回被替换节点原来的位置。所以：

- 选取压缩区间必须用**位置切片**（`nodes.slice(startIdx, endIdx + 1)`），不能用 `filter(seq >= start && seq <= end)`
- 用数值区间过滤会漏掉「位置在区间内、seq 在区间外」的节点，并让首尾比对必然失败

## 谱系表

任何内容被取代都登记一条，绝不静默删。

```js
{
  id:               "seq#2403",              // 原始位置
  originalLocation: "seq#2403",
  newLocation:      "/archive/xxx.txt",      // 新位置；未移动填 "-"
  replacedBy:       "spill-to-disk",         // 取代者
  digest:           "a1b2c3…"                // SHA-256，便于对实物
}
```

### `replacedBy` 取值

| 值 | 含义 |
|---|---|
| `lossless-fold` | 被第 1 层折叠 |
| `spill-to-disk` | 被第 2 层落盘 |
| `soft-pressure` | 被第 3 层驱逐 |
| `lossy-summarize` | 被第 4 层摘要 |

## 存档记录

`spillIfNeeded` 返回：

```js
{
  spilled: true,
  path:    "/archive/<会话标识>-<seq>.txt",  // 绝对路径
  sha256:  "…",                             // 原文校验
  size:    25089,                           // UTF-8 字节数
  preview: "…"                              // 头尾预览，≤5120 字符
}
```

存档文件名带**会话标识**：不同会话的 seq 会重号，只用 seq 会互相覆盖。

## 第 1 层逆变换记录

```js
{
  runs: [
    { start: 42, count: 8, lines: ["…"] }   // start = 原文真实行号
  ],
  original: "…",                            // 折叠前原文
  archivePath: "/archive/fold-xxx.txt",     // 原文存档（重启后可还原）
  digest: "…"
}
```

`start` 记录原文真实行号，还原时校验重建位置与之一致——防止记录被篡改后静默还原出错误内容。

## 内存状态

| 状态 | 作用域 | 说明 |
|---|---|---|
| 去重集合 | `WeakMap<session, {done, evicted}>` | 必须按会话隔离：seq 是会话内序号，进程级 Set 会让第二个会话起全部命中去重、静默失效 |
| 落盘信息 | `Map<`${sessionId}#${seq}`, info>` | 键必须带会话标识，否则跨会话串用 |
| 溢出重试计数 | `Map<agent, number>` | 按 agent 计，防溢出一失败就无限重试 |
| 压缩锁 | 事件流扫描 | 尾部有未配对 `compaction/start` 即视为锁定 |
