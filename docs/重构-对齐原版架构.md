# 重构：对齐原版架构（D18）

**目标**：把「摘要调用」从「拍平成纯文本」改回**原版的完整消息结构重建**，
以复用 provider 的 KV 缓存（省延迟、省成本），并把实现逐项对齐原版契约。

**起因**：交叉审计（`gemini-3.8-flash`）指出 `contract.js` 把消息序列扁平化后用
`\n` 拼接，剥离了 role 与结构，「导致大模型无法命中任何 KV Cache，
每次摘要都必须全量重算数万 Prompt Token」。

## 零、代码书写规范（本文所有代码块与后续实现都按此写）

这几条是硬要求，评审时按此逐条看，不达标即打回。

### 0.1 校验用卫语句，不用三元

**禁止**用三元表达式承担校验分支。三元把「失败路径」藏在表达式里，
读代码要来回对照两个分支才知道哪边是异常。

```js
// ❌ 反面：校验藏在三元里，读的人要反向推导
const seqs = Array.isArray(shadowedSeqs) ? shadowedSeqs : [];
const target = value === undefined ? fallback : value;

// ✅ 正确：卫语句提前退出，主流程一路到底
if (!Array.isArray(shadowedSeqs)) {
    return { messages: [] };
}
const seqs = shadowedSeqs;

if (value === undefined) {
    return fallback;
}
```

**唯一允许用三元的地方**：纯取值、无校验语义、且一眼能读懂的短表达式，
例如 `` `seq=${seq}` ``。**判空、判类型、判边界一律卫语句。**

### 0.2 可选字段用「按需追加」，不用条件展开

条件展开 `...(x === undefined ? {} : { tools: x })` 同样是把分支藏进表达式，
而且丢掉「这个键到底存不存在」的可读性。

```js
// ❌ 反面：一次读不出哪些字段是必带的
const request = {
    provider: target.provider,
    ...(input.tools === undefined ? {} : { tools: [...input.tools] }),
    ...(signal === undefined ? {} : { signal }),
};

// ✅ 正确：必带字段一个对象，可选字段逐条 if 追加
const request = { provider: target.provider, model: target.model };

if (input.tools !== undefined) {
    request.tools = [...input.tools];
}

if (signal !== undefined) {
    request.signal = signal;
}
```

### 0.3 逻辑段之间空一行，每段上方一行中文注释

代码块内按「一件事一段」切开，段间空行；每段上方一行中文注释说明这段在干什么。
不要写「初始化变量」这类废话注释，要写**为什么这样做**。

### 0.4 失败路径显式抛出，不靠返回值暗示

该失败就 `throw`，不要返回 `null` 让上层去猜「是没数据还是出错了」。

### 1.1 摘要输入是怎么造的

原版 `dsh-compaction-basic/lib/index.js:695-704`：

```js
function buildSummarizationInput(session, shadowedSeqs) {
  // ① 取最近一次请求的头：里面有工具定义与会话级配置
  const header = session.requestHeader();

  // ② 只看表面节点 0 是不是 system/message（是则单独取出，否返回 undefined）
  const head = systemHead(session, session.surface.nodes[0]);

  // ③ 把 system 事件投影成结构化 message；没有 system 头就是 null
  const system = head === undefined ? null : session.deriveEventMessage(head);

  // ④ 把选区内每条事件都投影成结构化 message，并丢掉投影结果为 null 的
  //    —— 保留 role 与 content 块，不拼字符串、不拍平
  const regionMessages = shadowedSeqs
    .map((seq) => session.deriveEventMessage(session.eventAt(seq)))
    .filter((message) => message !== null);

  // ⑤ 组装：有 tools 才带这个键；system 头放在消息最前
  return {
    ...(header?.tools === undefined ? {} : { tools: header.tools }),
    messages: system === null ? regionMessages : [system, ...regionMessages],
  };
}
```

**关键点三条**：

1. 用 `session.deriveEventMessage(event)` 把事件**还原成结构化 message**（保留 role 与 content 块）
2. system 头单独取出，放在消息列表最前
3. **带上 `header.tools`**（工具定义）

### 1.2 摘要请求是怎么发的

原版 `summarizeWithLlm`（`:292-338`）：

async function summarizeWithLlm(ctx, config, input, agent, signal) {
  // ① 定摘要用哪个模型：配置优先 → 最近一次请求路由 → agent 自身路由
  const latest = agent.session.requestHeader()?.config;

  const configured = config.summarizationProvider.length === 0 ? undefined : {
    provider: config.summarizationProvider,
    model: config.summarizationModel,
  };

  const agentTarget = agent.options.provider !== undefined && agent.options.provider.length > 0 ? {
    provider: agent.options.provider,
    model: agent.options.model,
  } : undefined;

  const target = configured ?? latest ?? agentTarget;

  // ② 拼消息：重放前缀 + 最后追加一条「压缩指令」的 user 消息
  const assembler = new BlockAssembler();

  const messages = [...input.messages, deepFreeze({
    role: "user",
    content: [{ type: "text", text: COMPACTION_INSTRUCTION }],
  })];

  // ③ 组请求：toolHistory / tools / sessionId 三个字段是复用 KV 缓存的关键
  const options = {
    provider: target.provider,
    model: target.model,
    messages,
    toolHistory: agent.session.toolHistory(),                          // 工具历史
    ...(input.tools === undefined ? {} : { tools: [...input.tools] }),  // 工具定义
    maxTokens: config.maxTokens,

    purpose: "compaction",
    ...(signal === undefined ? {} : { signal }),

  // ④ 流式收，用 BlockAssembler 聚合
  for await (const chunk of ctx.llm.stream(options)) assembler.push(chunk);

  // ⑤ 失败必须上抛，否则半截输出会被当成完整摘要提交
  const error = finishError(assembler.finish);
  if (error !== undefined) throw error;

  // ⑥ 只保留文本块，拼成摘要正文
  const rawOutput = assembler.blocks();
  const summary = summaryText(rawOutput);
  if (!summary.some((block) => block.text.trim().length > 0)) {
    throw new Error("summarization produced no text summary content");
  }

  return { summary, rawOutput, provider: options.provider, model: options.model, maxTokens: config.maxTokens };
}

**缺 `tools`、`toolHistory`、`sessionId`**，且 messages 是两条纯文本。

## 二、重构后的流程（每一步请求）

### 步骤 1：选区（不变，只补卫语句）

`compactIfNeeded` / `compactNow` → `_selectRange` → `{start, end}`。

输出：表面上的一段位置区间（配平、不劈开 tool 对、受 retain 约束）。

```js
// ① 选不出区间就没得压，直接退出（可压缩量太小 / 只剩 system 头 + 尾部保留区）
const selection = this._selectRange(session, retainTokens);
if (selection === null) {
    return null;
}

const { start, end } = selection;

// ② 转表面位置索引。不能用 seq 数值过滤——replace 会把新事件放回旧位置，
//    表面上 seq 并不单调（D17 已踩过这个坑）
const surfaceNodes = session.surface.nodes;

const startIdx = surfaceNodes.indexOf(start);
if (startIdx === -1) {
    return null;
}

const endIdx = surfaceNodes.indexOf(end);
if (endIdx === -1) {
    return null;
}

if (endIdx < startIdx) {
    return null;
}

const shadowedSeqs = surfaceNodes.slice(startIdx, endIdx + 1);
```

### 步骤 2：构造摘要输入（**改**）

新模块 `src/summary-input.js`，对外只有一个入口 `buildSummaryInput`。

```js
/**
 * 为摘要调用构造结构化输入。
 *
 * 对齐原版 buildSummarizationInput（basic:695-704）：保留宿主导出的
 * message 对象引用，不重建、不拼字符串，从而让摘要请求成为会话前缀的重放。
 */
export function buildSummaryInput(session, shadowedSeqs, logger) {
    // ① 入参卫语句：宿主缺失或选区不合法，返回空输入。本模块契约是「绝不抛错」
    if (session === undefined || session === null) {
        return { messages: [] };
    }

    if (!Array.isArray(shadowedSeqs)) {
        return { messages: [] };
    }

    if (shadowedSeqs.length === 0) {
        return { messages: [] };
    }

    // ② 宿主没有投影能力 → 走文本兜底，并警告一次（不静默降级）
    if (typeof session.deriveEventMessage !== "function") {
        warnOnce("宿主不支持 session.deriveEventMessage，摘要输入退回文本模式。", "missing", logger);
        return buildTextInput(session, shadowedSeqs);
    }

    // ③ 首选结构化路径；投影过程中崩溃 → 也退文本兜底，不能让摘要整体失败
    try {
        return buildStructuredInput(session, shadowedSeqs);
    } catch (error) {
        warnOnce("session.deriveEventMessage 调用失败，摘要输入退回文本模式。", "failed", logger);
        return buildTextInput(session, shadowedSeqs);
    }
}
```

结构化路径（对齐原版形状）：

```js
function buildStructuredInput(session, shadowedSeqs) {
    // ① 取工具定义。header 读不到只是不带 tools，不该阻断摘要
    let tools;
    try {
        const header = session.requestHeader();
        if (header !== undefined && header !== null) {
            tools = header.tools;
        }
    } catch {
        tools = undefined;
    }

    const messages = [];

    // ② system 头：仅当表面节点 0 是 system/message 才取出，放消息列表最前
    const headEvent = systemHeadEventOf(session);
    if (headEvent !== undefined) {
        const system = session.deriveEventMessage(headEvent);
        if (system !== null) {
            messages.push(system);
        }
    }

    // ③ 选区内逐条投影成结构化 message。null 是宿主对非消息事件的明确裁定，丢掉
    for (const seq of shadowedSeqs) {
        const event = session.eventAt(seq);
        if (event === undefined || event === null) {
            continue;
        }

        const message = session.deriveEventMessage(event);
        if (message === null) {
            continue;
        }

        messages.push(message);
    }

    // ④ 组装。tools 缺失时该键不存在，而不是 undefined 值
    const input = { messages };
    if (tools !== undefined) {
        input.tools = tools;
    }

    return input;
}
```

文本兜底（旧宿主 / 投影崩溃时用）：

```js
function buildTextInput(session, shadowedSeqs) {
    const parts = [];

    // ① system 头单独一行，避免与正文混在一起
    const headEvent = systemHeadEventOf(session);
    if (headEvent !== undefined) {
        const text = eventText(headEvent);
        if (text.length > 0) {
            parts.push(`${roleOf(headEvent)}: ${text}`);
        }
    }

    // ② 选区内逐条抽文本。抽取形状差异见 D17 P0 修复：user 挂 data.content，
    //    assistant / tool 挂 data.message.content，两处都要试
    for (const seq of shadowedSeqs) {
        const event = session.eventAt?.(seq);
        if (event === undefined || event === null) {
            continue;
        }

        // system 头已在上面单独拼过，这里跳过避免重复
        if (headEvent !== undefined && event.seq === headEvent.seq) {
            continue;
        }

        const text = eventText(event);
        if (text.length === 0) {
            continue;
        }

        parts.push(`${roleOf(event)}: ${text}`);
    }

    // ③ 一条都没抽到就别造空消息，交给上层按「无输入」处理
    if (parts.length === 0) {
        return { messages: [] };
    }

    return {
        messages: [{ role: "user", content: [{ type: "text", text: parts.join("\n\n") }] }],
    };
}
```

### 步骤 3：发摘要请求（**改**）

`summarize(input, agent, signal)`：入参 `input` 从字符串改为 `{messages, tools?}`。

```js
async summarize(input, agent, signal) {
    // ① 前置卫语句：路由、实现、入参，缺任一个立刻失败，不留半程工作
    const target = this._summaryTargetOf(agent);
    if (target === undefined) {
        throw new ManualCompactionError("summary", "tiered-compaction: 无摘要路由（summaryTarget 与会话路由均缺）");
    }

    const summarizeFn = this.config.summarizeFn ?? this._summarizeFnFromCtx();
    if (summarizeFn === undefined) {
        throw new ManualCompactionError("summary", "tiered-compaction: 无摘要实现（config.summarizeFn 或 ctx.llm 均缺）");
    }

    if (input === undefined || input === null) {
        throw new ManualCompactionError("summary", "tiered-compaction: 摘要输入缺失");
    }

    if (!Array.isArray(input.messages) || input.messages.length === 0) {
        throw new ManualCompactionError("summary", "tiered-compaction: 摘要输入不含任何消息");
    }

    // ② 拼消息：结构化前缀 + 最后追加一条压缩指令
    const messages = [
        ...input.messages,
        { role: "user", content: [{ type: "text", text: COMPACTION_INSTRUCTION }] },
    ];

    // ③ 组请求：必带字段一次写清
    const request = {
        provider: target.provider,
        model: target.model,
        messages,
        maxTokens: RESERVE_TOKENS,
        purpose: "compaction",
    };

    // ④ 可选字段逐条追加。缺失时键根本不存在，而不是 undefined 值
    if (input.tools !== undefined) {
        request.tools = [...input.tools];
    }

    const session = agent === undefined || agent === null ? undefined : agent.session;

    if (session !== undefined && typeof session.toolHistory === "function") {
        request.toolHistory = session.toolHistory();
    }

    if (session !== undefined && session.id !== undefined) {
        request.sessionId = session.id;
    }

    if (signal !== undefined) {
        request.signal = signal;
    }

    // ⑤ 发请求
    const summary = await summarizeFn(request, signal);

    // ⑥ 空摘要拒绝提交：宁可报错，也不写一条空检查点覆盖原文
    if (summary === undefined || summary === null || summary.length === 0) {
        throw new ManualCompactionError("summary", "tiered-compaction: 摘要结果为空，拒绝提交");
    }

    return { summary, provider: target.provider, model: target.model, maxTokens: RESERVE_TOKENS };
}
```

/**
 * 把摘要正文包进与 basic 相同的检查点框架。
 *
 * 首段带开标签、末段带闭标签：投影层靠这两个标记识别检查点。

function frameSummaryText(summary) {

## 五、风险与取舍（写在前面，免得验收时争论）

| 风险 | 说明 | 应对 |
|---|---|---|
| KV 缓存收益未实测 | 我们只能验证「结构传对了」，没法在本地测 provider 侧缓存命中率 | 验收只断言请求结构；缓存收益留待线上观察 |
| `toolHistory` 可能很大 | 传完整工具历史会增大请求体积 | 原版也这么传，先对齐；线上发现过大再做裁剪 |
| 旧宿主兜底路径质量较低 | 文本拼接丢掉结构，KV 缓存仍命中不了 | 明确记 warn，不静默降级 |
| `deriveEventMessage` 是内部 API | 宿主版本变动可能失效 | 用存在性判断守卫，缺失即走兜底 |
| 老测试夹具是假会话 | 桩的 `append` 不派发 `session/event`，曾放走 OOM 级 bug | 本轮新测试一律按真实派发语义写；老夹具升级另开任务 |
| `summarize` 入参语义变了 | 从字符串改为 `{messages, tools?}`，可能影响外部调用方 | 全仓只有 `_runTransaction` 一处调用；`config.summarizeFn` 是外部注入点，需在派单里明确告知新签名 |
