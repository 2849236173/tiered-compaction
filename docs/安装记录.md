**为什么选 headless 模板**：headless 是一次性任务型 app，不监听端口、不启动 Web UI、跑完即退——最适合「装进去看能不能加载」，不会像 `web` 模板那样起服务占端口。
> 踩过的坑：最初用 `web` 模板建 `m6s`，跑 `dsh --profile m6s --from-default-profile web` 时**参数被转发给 app**，变成了「启动 web 服务」，误起了一个监听 3080 的实例。已立即 kill，`Get-NetTCPConnection -LocalPort 3080` 确认无残留、无 node 进程残留。**教训：`--from-default-profile` 必须和其他 launcher 参数一起放在 app 参数之前，且头一次跑一定要带 `--dump-config` 这类只读开关先验证解析结果。**

## 2. 安装步骤（可复现）


## 5. ⛔ 上生产的 4 个阻塞项（交程序员，不是运维能改的）

### 问题 1：包缺 `dsh.bundle` 声明，无法作为 profile 层安装

`dsh plugin add` 报：
```
dsh: warning: @local/dsh-tiered-compaction declares no dsh.bundle
     — installed as a plain dependency, not a profile layer
```
对比 `ds-bot` 的 `package.json`：
```json
"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
```
**影响**：包自带的 `cordis.patch.yml` 不会被自动应用，必须由用户在 profile 补丁里手写 `insert`。别人装这个插件会一头雾水（装了但没生效）。
**修法**：`package.json` 加 `dsh.bundle.patch` 指向自己的 `cordis.patch.yml`（该文件已存在且内容正确）。

### 问题 2：`src/index.js` 注释与实际里程碑不符（会误导后来者）

第 26-29 行仍写着「M2 骨架期服务…当前为 M2 空实现」「后续 M3/M4 将把四层管线挂在同一服务实例上」，但 `ef9b26b` 已完成 M4.5 wiring，`TieredCompactionEngineService` 已真实接管。
**影响**：不影响功能，但运行时日志会打出「当前为 M2 空实现」，验收时极易误判成「没接线」。
**修法**：更新注释与 `ctx.logger.info` 文案。

### 问题 3：`version` 仍是 `0.1.0-m2`

`ef9b26b`（wiring）、`a77ff0f`（探针）之后版本号没跟。装上后 `dsh plugin why` 看到的是 m2，无法判断实际跑的是哪份代码。
**修法**：`package.json` 版本升到 `0.1.0-m6`（或按你们口径）。

### 问题 4：`npm test` 脚本口径在 Node 24 下会把探针当测试跑

`package.json` 里 `"test": "node --test test/"`，Node 24 的 `--test` 目录模式会把 `test/` 下所有 `.mjs`（含 `m5-independent-probe.mjs`、`m6-dual-state.mjs`、`m6-real-llm.mjs` 三个**非 node:test 格式**的独立探针）都当测试文件执行，结果 `npm test` 直接 fail：
```
✖ test (152ms)  'test failed'
ℹ tests 1 / pass 0 / fail 1
```
**但实际代码是好的**——逐个跑真实测试文件全绿：
| 文件 | tests | pass | fail |
|---|---|---|---|
| `test/index.test.js` | 3 | 3 | 0 |
| `test/m3-layers.test.js` | 7 | 7 | 0 |
| `test/m4-layers.test.js` | 8 | 8 | 0 |
| `test/m45-wiring.test.js` | 6 | 6 | 0 |
| **合计** | **24** | **24** | **0** |
另 `m5-independent-probe.mjs` 单跑 7 过 0 败。
**修法**：脚本收窄为 `node --test test/*.test.js`（或把探针移到 `test/probes/`）。**这是会挡住 CI 的口子，优先级高。**
