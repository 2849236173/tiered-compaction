# 第 4 层 · 有损摘要

**目标**：前三层压不下去时，用一次 LLM 调用把一段历史压成续做可用的检查点。唯一消耗 LLM 的层。

## 触发阈值

```
阈值 = 窗口 − max(16k, 窗口×5%) − 摘要预留(20k)
```

并且有下限保护：不低于窗口的 **82%**。

**为什么要有下限**：公式在小窗口下会算出很低的阈值（例如 128k 窗口算出 60%），导致压缩过于频繁；下限保证至少到 82% 才压。

**为什么预留 20k**：摘要是一次 LLM 调用，需要输出预算。预算不足时会撞上输出上限，产出的摘要被截断——然后为了压得更小又触发下一次摘要，形成死循环。预算提前预留，从根上杜绝这条死循环。

## 摘要输入必须是会话前缀的重放

这是本层最关键的设计。

**错误做法**：把选区内容拼成一段纯文本，作为一条 user 消息发给模型。

后果：role、content 块结构、工具定义全部丢失。在 provider 看来这是一段**全新文本**，KV 缓存一次都命中不了——每次摘要都要重算整个前缀（真实会话测到 218 万字符）。

**正确做法**（对齐 DSH 官方 `dsh-compaction-basic`）：

```js
// 1. system 头单独取出，放消息列表最前
// 2. 选区内每条事件用宿主投影还原成结构化 message（保留 role 与 content 块）
// 3. 带上请求头里的 tools 定义
// 返回 { messages, tools? }
```

然后请求时再追加一条压缩指令：

```
messages = [...会话前缀, { role: "user", content: 压缩指令 }]
options  = { provider, model, messages, tools, toolHistory, sessionId, maxTokens, purpose }
```

**这样做的判据**：摘要请求的 messages 必须是正常对话请求的 messages 的**严格前缀**。

相同则那段前缀的 KV 在正常对话时已建立，摘要调用直接复用；顺序、条数、内容任何一处不同，就一次都命中不了。

实测（真实会话 4591 条事件、1409 个表面节点）：摘要请求 1184 条消息与正常请求逐字节相同，零差异。

## 检查点包装

摘要正文写入会话时包成三段：

```
[固定前言 + <compacted-summary>]
[摘要正文]
[</compacted-summary>]
```

首尾标签是投影层识别检查点的依据，缺任一个，检查点在续做时不会被当成已确立背景。

## 摘要正文校验

正文必须**非空白**：`summary.trim().length === 0` 即拒绝提交。

只判 `length === 0` 会放过 `"   "`、`"\n\n"` 这类纯空白——提交后模型看到的是「有检查点但什么也没说」，比没有检查点更坏：它以为上下文已确立，实际信息全丢了。

## 提交前的护栏

| 护栏 | 作用 |
|---|---|
| 压缩锁 | 事件流尾部有未配对的 `compaction/start` 时拒绝进入，防并发改表面 |
| 取消检查 | 摘要前后各查一次 signal，用户取消后不提交 |
| 选区稳定性 | 摘要期间会话可能变化，提交前校验选区仍可替换，否则丢弃摘要 |
| 变小判据 | 摘要必须比被取代内容小，否则拒绝提交（防「压缩后更大」） |

**关于变小判据的分母**：只计入**选区内的**内容。会话 system 头不计——它不在选区里，压缩后仍留在会话中，计入会让分母凭空变大，判据被放水到几乎永远成立。

## 失败处理

- `finish.kind = "error" | "aborted"` → 抛真实错误，不伪装成「摘要为空」
- `finish.kind = "max-tokens"` → 抛 `MAX_TOKENS`，因为截断的摘要是残缺的
- 任何失败都补一条配对的 `compaction/end`，否则压缩锁永久持有，后续全部 busy

## 验收要点

| 项 | 标准 |
|---|---|
| 结构等价 | 摘要 messages 是正常请求的严格前缀 |
| KB 缓存字段 | `tools` / `toolHistory` / `sessionId` 三个都在 |
| 三段包装 | 首段含 OPEN_TAG、末段为 CLOSE_TAG |
| 空白拒绝 | 纯空白摘要拒绝提交 |
| 取消 | 摘要期间取消则不提交 |
| 失败上抛 | LLM 失败暴露真实原因，不降级成「摘要为空」 |
| 旧宿主兼容 | 无投影能力时退回文本模式并告警，不崩 |
